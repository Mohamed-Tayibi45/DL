# حساب دالة التكلفة (Cost Function) في الانحدار الخطي (Linear Regression)

قبل تحديث معاملات النموذج باستخدام **Gradient Descent**، يجب أولًا قياس مدى جودة النموذج الحالي في التنبؤ بالبيانات. ويتم ذلك باستخدام **دالة التكلفة (Cost Function)**.

# مثال باستخدام معادلة التوقع

نفترض أن معادلة التوقع هي:

```text
h(x) = 5 + 2x
```

---

## جدول البيانات

| x | y (القيمة الحقيقية) |
|--:|---------------------:|
| 1 | 8 |
| 2 | 10 |
| 3 | 11 |
| 4 | 14 |
| 5 | 16 |

---

## 1. قيم معاملات النموذج (Parameters)

نفترض أن النموذج تعلم القيم التالية:

```text
θ₀ = 5
θ₁ = 2
```

لذلك تصبح معادلة التوقع:

```text
h(x) = θ₀ + θ₁x
h(x) = 5 + 2x
```

---

## 2. حساب القيم المتوقعة

نطبق معادلة التوقع على كل قيمة من قيم `x`.

| x | y الحقيقي | h(x) = 5 + 2x |
|--:|----------:|--------------:|
| 1 | 8 | 7 |
| 2 | 10 | 9 |
| 3 | 11 | 11 |
| 4 | 14 | 13 |
| 5 | 16 | 15 |

---

## 3. حساب الخطأ (Error)

الخطأ لكل مثال يحسب بالعلاقة التالية:

```text
Error = h(x) - y
```

| x | y | h(x) | الخطأ |
|--:|--:|------:|-------:|
| 1 | 8 | 7 | -1 |
| 2 | 10 | 9 | -1 |
| 3 | 11 | 11 | 0 |
| 4 | 14 | 13 | -1 |
| 5 | 16 | 15 | -1 |

---

## 4. تربيع الخطأ

لأن بعض الأخطاء سالبة وبعضها موجبة، فإننا نقوم بتربيعها حتى تصبح جميعها موجبة.

| الخطأ | مربع الخطأ |
|------:|-----------:|
| -1 | 1 |
| -1 | 1 |
| 0 | 0 |
| -1 | 1 |
| -1 | 1 |

مجموع مربعات الأخطاء:

```text
1 + 1 + 0 + 1 + 1 = 4
```

---

## 5. حساب دالة التكلفة (Cost Function)

معادلة دالة التكلفة في الانحدار الخطي هي:

```text
J(θ₀, θ₁) = (1 / (2m)) × Σ(h(x) - y)²
```

حيث:

- `J` : قيمة دالة التكلفة.
- `m` : عدد أمثلة التدريب.
- `Σ` : مجموع جميع مربعات الأخطاء.

في مثالنا:

```text
m = 5
```

ومجموع مربعات الأخطاء:

```text
Σ(h(x) - y)² = 4
```

إذن:

```text
J = 4 / (2 × 5)
```

ثم:

```text
J = 4 / 10
```

وأخيرًا:

```text
J = 0.4
```

```text

θ₁ = 2
```

معادلة التوقع:

```text
h(x) = 5 + 2x
```

مجموع مربعات الأخطاء:

```text
4
```

قيمة دالة التكلفة:

```text
Cost = 0.4
```

---

# ماذا تعني قيمة Cost؟

كلما اقتربت قيمة **Cost** من **الصفر (0)** كان النموذج أفضل في التنبؤ.

أما إذا كانت قيمة **Cost** كبيرة، فهذا يعني أن النموذج لا يتنبأ بالبيانات بدقة، ويجب تحسين معاملات **θ₀** و **θ₁** باستخدام خوارزمية **Gradient Descent**.

# إيجاد θ₀ و θ₁ باستخدام Gradient Descent (التكرار الأول)

هذا هو المثال التعليمي الأكثر استخدامًا لفهم كيفية عمل خوارزمية **Gradient Descent** في الانحدار الخطي (Linear Regression).

> **ملاحظة:** لا يدعم GitHub معادلات **LaTeX** داخل ملفات `README.md`، لذلك سيتم كتابة جميع المعادلات بصيغة نصية (Text).

---

# جدول البيانات

| x | y |
|--:|--:|
| 1 | 2 |
| 2 | 3 |
| 3 | 5 |
| 4 | 4 |
| 5 | 6 |

عدد أمثلة التدريب:

```text
m = 5
```

نفترض أن معاملات النموذج تبدأ بالقيم التالية:

```text
θ₀ = 0
θ₁ = 0
```

ومعدل التعلم (Learning Rate):

```text
α = 0.1
```

معادلة التوقع هي:

```text
h(x) = θ₀ + θ₁x
```

وبما أن:

```text
θ₀ = 0
θ₁ = 0
```

فإن معادلة التوقع في بداية التدريب تصبح:

```text
h(x) = 0
```

---

# الخطوة 1: حساب التوقع والخطأ

الخطأ يحسب بالعلاقة:

```text
Error = h(x) - y
```

| x | y | h(x) | h(x) - y |
|--:|--:|------:|----------:|
| 1 | 2 | 0 | -2 |
| 2 | 3 | 0 | -3 |
| 3 | 5 | 0 | -5 |
| 4 | 4 | 0 | -4 |
| 5 | 6 | 0 | -6 |

---

# الخطوة 2: تحديث θ₀

معادلة التحديث:

```text
θ₀ = θ₀ - α × (1 / m) × Σ(h(x) - y)
```

### حساب مجموع الأخطاء

```text
-2 + (-3) + (-5) + (-4) + (-6) = -20
```

### التعويض في المعادلة

```text
θ₀ = 0 - 0.1 × (-20 / 5)
```

```text
θ₀ = 0 - 0.1 × (-4)
```

```text
θ₀ = 0 + 0.4
```

النتيجة:

```text
θ₀ = 0.4
```

---

# الخطوة 3: تحديث θ₁

معادلة التحديث:

```text
θ₁ = θ₁ - α × (1 / m) × Σ((h(x) - y) × x)
```

### حساب (h(x) - y) × x

| x | h(x) - y | (h(x) - y) × x |
|--:|----------:|----------------:|
| 1 | -2 | -2 |
| 2 | -3 | -6 |
| 3 | -5 | -15 |
| 4 | -4 | -16 |
| 5 | -6 | -30 |

### حساب المجموع

```text
-2 - 6 - 15 - 16 - 30 = -69
```

### التعويض في المعادلة

```text
θ₁ = 0 - 0.1 × (-69 / 5)
```

```text
θ₁ = 0 - 0.1 × (-13.8)
```

```text
θ₁ = 0 + 1.38
```

النتيجة:

```text
θ₁ = 1.38
```


|--:|--:|-------------------:|

# ماذا يحدث بعد ذلك؟

بعد الحصول على القيم الجديدة:

```text
θ₀ = 0.4
θ₁ = 1.38
```

نقوم بالخطوات التالية:

1. نحسب التوقعات الجديدة باستخدام المعادلة الجديدة.
2. نحسب الأخطاء الجديدة.
3. نحسب قيمة **Cost Function**.
4. نكرر تحديث **θ₀** و **θ₁** مرة أخرى.

يسمى كل تكرار من هذه العملية **Iteration**.

تستمر خوارزمية **Gradient Descent** في تنفيذ هذه الخطوات حتى:

- تستقر قيم **θ₀** و **θ₁**.
- تصل **Cost Function** إلى أصغر قيمة ممكنة.
- يصبح النموذج قادرًا على تقديم تنبؤات دقيقة.
